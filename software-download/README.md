# Software Download

Download the Windows installer here:

- [DuilioToolsInstaller.exe](DuilioToolsInstaller.exe)

## Install on Windows

1. Download `DuilioToolsInstaller.exe`.
2. Double-click the installer.
3. Follow the installation steps.
4. Start `Duilio Tools` from the Windows Start menu or desktop shortcut.

## Use

1. Power DUILIO F4 with the intended setup.
2. Connect the board to the PC.
3. Open `Duilio Tools`.
4. Connect to the board.
5. Read the current configuration.
6. Change the parameters you need.
7. Write the configuration back to the board.
8. Test the board before connecting the real load.

## First use

- Start without motors or dangerous loads connected.
- Use only one intended 5 V power source.
- Verify communication before changing settings.
