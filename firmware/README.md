# Firmware

This public repository does not publish the private firmware source tree.

For end users, the relevant public material is:

- board behavior documented in the hardware manual
- configuration and diagnostics through Duilio Tools
- simplified integration notes for supported control scenarios

Firmware-related user information is summarized in [../tools/README.md](../tools/README.md) and in the hardware manual chapters covering startup, usage, communication, and service.
