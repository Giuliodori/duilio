# Beginner FAQ

Quick answers for first-time visitors.

## What is DUILIO F4?
DUILIO F4 is a ready-to-use motion controller that turns RC or USB commands into safe, coordinated motor control without requiring firmware development.

## Is DUILIO F4 a development board or a finished product?
DUILIO F4 is a controller board designed to be used as a practical motion controller, with a baseline firmware already installed.

## Do I need to write code to use DUILIO F4?
No. DUILIO F4 can be configured with Duilio Tools without writing code for common use cases.

## Is DUILIO F4 only for robots?
No. DUILIO F4 can be used in robots, vehicles, mobile platforms, positioning systems, and custom machines.

## Do I need a PC or a Raspberry Pi?
No. DUILIO F4 can work standalone using an RC receiver. PC or Raspberry Pi control is optional.

## Can I control DUILIO F4 from a PC or Raspberry Pi?
Yes. DUILIO F4 can be controlled over USB using the provided Python or Arduino libraries.

## Why does DUILIO F4 cost so little compared to similar systems?
DUILIO F4 is still in a validation phase. Keeping the price accessible is an intentional choice, while certification and larger-scale production are handled separately from the public FAQ.

## Is DUILIO F4 safe to use?
Yes. Safety features such as enable logic, failsafe states, and speed limiting are built in.

## How long does it take to get something moving?
With the baseline firmware, basic motion can be achieved in minutes.

## Is DUILIO F4 a new product?
Yes. DUILIO F4 is an actively evolving project.

## If I buy DUILIO F4 now, how do I get updates?
Software and firmware updates are distributed through the project tools and repository workflow. Check the current release notes and tools before assuming that every update is installed automatically.

## Can I contribute to the project?
Yes. Any contribution is welcome, from feedback to testing and development.

## Can I ask for help on my specific project?
Yes. Asking is free. The availability and depth of support depend on the request.

## How long does it take to receive a board?
Boards in stock ship within about 2 days. Pre-orders depend on production batches but typically take no more than 4 weeks.
